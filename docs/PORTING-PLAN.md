# PCL-CE / HMCL 功能移植计划（SCL 启动器）

**原则**：只移植功能与交互思路，不复制任何代码；界面始终用 SCL 自己的设计语言。
**节奏**：每批一个版本（1.1.0 → 1.2.0 → …），批批可验收。
**交付**：每批完成后**同时**更新两处 ——
①仓库 `dist/`（本地直接双击 `dist/StarCore-win-x64/StarCore.exe`）；
②GitHub Releases。
**质量**：每批跑完 前端静态检查 → 编译 → 界面资源哈希校验 → 包内容校验 四道闸才发版。

> 前置结论：每个实例天然是独立目录（mods / saves / config 全套），
> 启动工作目录即实例路径 —— PCL 的"版本隔离"已天然成立（v1.1.0 已标注）。
> 但 PCL 的隔离是**可选模式**（隔离 / 共用），第 3 批把它做成可切换。

## 第 1 批 ✅ · 下载源测速与版本隔离标注（v1.1.0，已发）

- 下载源测速：并行实测各源延迟与吞吐（256KB 版本清单），一键切最快
- 版本隔离：概览页"已启用"徽章 + 打开实例文件夹

## 第 2 批 · Java 中心（v1.2.0，HMCL 强项）

- 手动添加任意 Java 目录（校验 bin/java 存在、识别版本）
- Java 运行自检（实测 `java -version`，失败给出具体原因）
- 内存自动推荐（按总内存与实例是否有模组，给出建议值）
- JVM 参数模板（原版 / 轻量模组 / 重量模组 三档预设）

## 第 3 批 · 实例管理深度 I（v1.3.0，对标 PCL）

- **版本隔离模式切换**：每实例可选「隔离」或「共用指定目录」
- **游戏目录管理**（HMCL）：多游戏目录注册与切换
- 实例图标自定义（本地图片）
- 实例排序 / 搜索 / 隐藏

## 第 4 批 · 实例管理深度 II（v1.4.0）

- **补全文件**（PCL）：一键修复缺失的库 / 主 jar / 资源
- **修改版本 JSON**（高级编辑器 + JSON 校验）
- 多开支持（同实例多进程并行，PCL/HMCL 都有）
- 服务器地址预设（安装时可选同时添加）

## 第 5 批 · 存档与世界（v1.5.0）

- 存档列表：level.dat 读出 游戏模式 / 种子 / 最后游玩 / 游戏版本
- 备份与恢复；「启动前自动备份」开关（PCL 的招牌安全感）
- 删除 / 重命名 / 在文件夹中显示

## 第 6 批 · 启动体验（v1.6.0，PCL 招牌）

- 游戏窗口标题自定义（支持 {实例名} {版本} 变量）

- 托盘最小化（`CloseToTray` 补实现）
- 启动前命令与环境变量的图形化编辑

## 第 7 批 · 服务器管理（v1.7.0，PCL 特色功能）

## 第 8 批 · 整合包（v1.8.0，体量最大）

## 第 9 批 · 崩溃诊断 + 实时日志（v1.9.0，HMCL 强项）

- **实时游戏日志窗口**（PCL 的游戏输出面板：启动后实时滚动游戏输出）

  自动配置端口与白名单、面板远程管理
